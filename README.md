# Sayak Satpati — Portfolio

Static, responsive portfolio site in `index.html`. It is built with plain HTML, CSS, and JavaScript; no build step or external assets are required.

## Publish with GitHub Pages

1. Create a public repository named `sayak-portfolio` under `SayakSatpati07`.
2. Upload `index.html` and this `README.md` to the root of the `main` branch.
3. In **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. The site will be available at `https://sayaksatpati07.github.io/sayak-portfolio/` after GitHub Pages finishes its first deployment.
