# Sayak Satpati — Portfolio

**Live portfolio:** <https://sayaksatpati07.github.io/sayak-portfolio/>

Static, responsive portfolio site in `index.html`, built with plain HTML, CSS, and JavaScript. No build step or external assets are required. GitHub Pages is configured to deploy from the root of the `main` branch.

## Content notes

- Project summaries reflect the supplied resume and the linked public source repository.
- The resume’s phone number, street address, student registration number, and photograph are not published here.
- Missing project metrics, validation details, and outcomes are identified as not reported instead of being invented.
- The prompt lab is a local interactive example. It does not call an AI service or transmit the text entered in it.
